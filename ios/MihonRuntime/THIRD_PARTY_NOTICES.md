# Embedded extension runtime

Kuchie uses these components when the optional iPhone extension runtime is included.

- OpenJDK Mobile is distributed under GPLv2 with the Classpath Exception. The source revision is [fc10224720ee1c109b1207daeba8878822bb5363](https://github.com/openjdk/mobile/tree/fc10224720ee1c109b1207daeba8878822bb5363). The release uses [ios-tools at f8524c91c012040e40e7f8af34e7a0f11af0da83](https://github.com/openjdk-mobile/ios-tools/tree/f8524c91c012040e40e7f8af34e7a0f11af0da83) and the [embedded OpenJDK v16 build instructions and patches](https://github.com/1Selxo/Mangatan/tree/8b516608909295b9f9fddc667a88a96c2ebf146c/tool/openjdk).
- M-Extension-Server is distributed under MPL 2.0. The [iOS v16 source revision](https://github.com/1Selxo/M-Extension-Server/tree/a8149c743c8b31a8e080adcef93be6e71e290fde) includes its license. Dependency notices are bundled in the server archive.
